# September 2026 Sales Analysis

This project analyzes the electronics sales dataset, cleans invalid rows, calculates
sales metrics, and generates a final report in a readable text format. The main
project entry point is the notebook in the project root, while the data and output
folders hold the source CSV and generated report.

## Project goals

The workflow follows the brief step by step:

1. Read the sales export using the csv module.
2. Clean quantity and unit price values and reject invalid rows.
3. Calculate total revenue and per-product revenue totals.
4. Rank the top products by revenue with a stable alphabetical tie-break.
5. Find transactions above the KES 50,000 threshold.
6. Calculate mean, median, minimum, and maximum transaction revenue.
7. Verify the custom calculations against pandas.

## How to run

Open and run all cells in the notebook named sales_analysis.ipynb from the project
root. The notebook:

- prints the total rows and column names
- cleans and validates the sales data
- computes the revenue metrics
- verifies the results against pandas
- saves the final report to output/sales_report.txt

## Data cleaning rules

- Strip whitespace and commas before converting values to floats.
- Remove a leading KES prefix from currency strings.
- Reject blank values, N/A entries, and malformed numbers.
- Skip rows where quantity or unit price is missing, invalid, or non-positive.
- Calculate revenue as quantity times unit price when the raw revenue field is absent.
- Preserve the sale id and skipping reason for invalid rows in the output summary.

## Output included in the report

The final report includes:

- total revenue
- revenue by product
- top 3 products
- high-value transactions above the threshold
- transaction statistics
- pandas verification summary
